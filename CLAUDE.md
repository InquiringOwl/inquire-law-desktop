# Inquire Law: working brief

Read this first in every session. Keep it short and current: update it in the same commit as any change it describes.

## What Inquire Law is
A desktop knowledge console (Electron) for law students that maps each subject as a Civ V-style skill tree: Menu → Dictionary → a subject → its Field map → a field's tree → lesson pages (Concept · Intermediate · Formal + an interactive model). It is a **clone of Inquire 1.19.0** (`~/Documents/codex-desktop`, repo `InquiringOwl/inquire-desktop`) with **every piece of Inquire's content removed**: no dictionary subjects, trees, lessons, labs, glossary entries, achievements, story art, menu screenshots or math checks. The UI, preferences, formats, notes, glossary engine, achievements engine, main menu, dictionary, field maps and the 1.19.0 block-lesson format are kept. **Never edit Inquire's folder from this project**, and never copy its content in.

- **Content today**: one open subject, **Lesson Template** (`lesson-template`, group Format Reference), with one charted field `template-field` whose tree holds `lesson-template` (the full block lesson filled with [placeholder] text: `web/content/template-field/lesson-template.js`, model `web/labs/template.js`, exposes `set`/`plus`/`play`, publishes `n`/`runs`/`result`) and one planned node `template-next`, plus a planned field `template-planned`. Copy it to start a real lesson.
- **Law subjects** (all `locked`, "Not yet charted", in `DB.subjects`, data.js): 1L Foundations (cyan): Contracts, Torts, Civil Procedure, Criminal Law, Constitutional Law, Property, Legal Research & Writing. Upper-Level Core (magenta): Evidence, Criminal Procedure, Professional Responsibility, Business Associations, Wills Trusts & Estates, Federal Income Tax, Administrative Law, Family Law, Commercial Law (UCC), Conflict of Laws. Practice & Perspectives (lime): Trial Advocacy, Negotiation & ADR, International Law, Intellectual Property, Environmental Law, Jurisprudence, Legal History. Format Reference (theme colour): Lesson Template. Group colours map to `--g-stem/--g-hum/--g-soc` (names kept from Inquire) in `DB.glossaryGroupColour` (data-glossary.js).
- **To chart a subject**: set its `status: "open"`, add `DB.subjectMaps[<id>]` (groups, eras, mapLine, mapSub, `accent` = its group's), its `DB.fields` (with `subject`), `DB.trees[<field>]` (`nodes`, `planned`), one content file per lesson in `web/content/<field>/<id>.js` (copy the template), a lab per lesson in `web/labs/`, glossary entries in `web/glossary/<subject>.js` (`DB.addGlossary`), an entry in `DB.menuSlides` with a lab screenshot `app/menu/<key>.jpg`. Big subjects can live in their own `web/src/data-<subject>.js` (loaded after data.js automatically). Defaults when a route names no subject/field: `DB.defaultSubject` / `DB.defaultField` (data.js; were "mathematics"/"arithmetic" in Inquire).
- **Story panels** (Inquire's English feature: tagged passages + `DB.posTags`/`DB.parseStory`) are still in the engine and could carry case excerpts; the current tag set is Inquire's parts of speech, a placeholder until a Law tag set is designed.
- **Achievements**: engine kept, catalogue empty (see below). **Glossary**: engine kept, 0 entries.
- **Lab kits** kept as engine: `web/kits/universal`, `categorical` (plane, stepper, quiz, demo storyboards), and `subjects/math.js`, `cs.js`, `music.js` (notes widgets need `CSRules`/`MusicTheory`; plane/stepper reference `MathRules`). Inquire's trig/precalc/english kits were not copied.
- Look: EVE Online-inspired, same palette and fonts as Inquire: amber `#F2B84B` (c1), cyan `#5CC8E0` (c2), pink `#F07CA0` (c3), violet `#B49BFF` (c4), green `#7BD88F` (c5); magenta `#D97AE6` and lime `#B5D65A` are group accents. Fonts STIX Two Text, IBM Plex Sans/Mono, Saira Semi Condensed (bundled in `app/fonts`).

## Lesson style guide (from Inquire 1.18.4–1.19.0; the reference page here is the Lesson Template)
Spec with field names: `docs/subjects/LAYERS.md`. This is the house style in one place; follow it unless Devon says otherwise.

**Look and feel**
- EVE Online console: dark glass windows (`.win`: `--win-1/-2` gradient, thin `--line` border, a bright corner tick top-left and a fainter one bottom-right in `--frame`), header strips (`.win-h`: small uppercase Saira label with letter-spacing + a glowing square dot). UI chrome always uses `var(--frame)` (follows the theme); c1–c5 are for content only. Serif (STIX Two) for headlines, leads and math; IBM Plex Sans for body; Saira uppercase, tracked, 10.5–12 px for labels/eyebrows; Plex Mono for counters ("1 of 6", "Solved 0 of 5").
- Section headings (`.lyr-body h2`): lit diamond, title, fading rule in `--frame`. Window titles inside panels: large serif, Title Case where Devon asked for it (the Intermediate Why: "Why a Method Beats a Guess").
- Symmetry matters: side-by-side boxes share top **and** bottom edges (stretch the grid, give both the same header bar); a rail or list that would leave empty space on the right fills the width (two columns: the step/words on the left, why/your move/math on the right, `ol.method.m2`) rather than hugging the left; an incomplete last row of cards is centred (Formal practice: 3 + 2 centred); Why panels span the full content width on every tab. Check at 1440, ~1000 and 420 px.
- Gold is reserved for progress: the topic-bar **Next lesson** button (`.next-btn`, after Mark as mastered). Green = solved/correct/mastered, red = where it goes wrong / mistakes, amber numbers + violet objects = colour cues.
- Bottom pager: two mirrored console cards, **◀ Previous lesson** left and **Next lesson ▶** right (`.pg-b.pg-prev/.pg-next`: arrow cell on the outer edge, Saira eyebrow, serif lesson title, mirrored corner ticks, glow on hover). At the first/last lesson the empty side becomes "Back to <field> tree", so the pair is always symmetric.

**Page shape**
- Tabs Concept · Intermediate · Formal as one `.win` strip above the header; the lab never changes between tabs, only the lede and the text below it.
- Every tab: **what → why → where it goes wrong → the rest.** What = a console header window (The question / The task / The definition) with the live figure from the lab ("Live from the model") and Jump-to links. Why + where share one `.win.why` panel ("Why it matters" label in `--frame`, "Where it goes wrong" in red; side by side in Concept, stacked in Formal, Intermediate has only the why).
- Concept: the question → 3 idea cards (title + real math term chip + 5th-grade sentence + animated storyboard + ▶ Try-it chip that drives the lab) → **Count it together** (one continuous situation: left "The situation" box with a still picture that steps with each line, right "One step at a time" box; the first line already shows, then each next line waits for a predict question; "Just show the line" / "Show all") → history timeline (full story folded, sources linked) → why │ where → "Where you will meet it" as number tiles (big figure, role, tap to open the scene with real numbers and a takeaway).
- Intermediate: the task → "What the model shows" key cards from the legend (symbol, name, plain description, Try chip) → the method as a numbered rail, each step with a **Why** line and, on some steps, a **Your move** box (do it in the lab, **Check my move**, ticks itself off from `k.publish` values, "Moves done" bar) → Why panel → Everyday tasks as tiles that are problems (typed answer + Check, hint, worked solution line by line with predict questions, small picture, Solved bar).
- Formal: the definition (boxed `.display` statement inside the header) → vocabulary cards (symbol, textbook term, definition, "You met it as" = the everyday name from the earlier tabs) with the full formal statement folded below → why (exact words) stacked over the mistakes table (Mistake red │ Correction green) → "Writing a … problem": the same situation from Concept rewritten textbook-style as a numbered rail, words left and the math box right → **Your turn**: 5 practice cards (context eyebrow, numbered question, labelled typed inputs, Check, hint after 2 tries, worked answer, Unsolved/Solved badge, progress bar, fires `inquire:quiz`).

**Voice and how ideas are introduced**
- Concept and Intermediate: 5th-grade reading level, adult tone, short sentences, no fluff. Formal: law-school precision and standard terminology (the black-letter rule, its elements and its sources: cases, statutes, Restatements, model rules), plain colour (no cues).
- Introduce every idea from something the learner can see or do: name the everyday version first, then the real term (the term chip on idea cards, "You met it as" on vocabulary). Every block points at something in the lab (a Try chip, a Your move, a live figure); nothing stands alone.
- Illustrate problems with one concrete situation carried through all three tabs (for Law: one fact pattern followed from start to finish), real practice settings with real details, and a picture (`InquireDemo` storyboards: no GIFs, CSS-variable colours, still frame under reduced motion).
- Solve problems by showing the work line by line, asking the learner to **predict** the next line before revealing it, with a hint, a kind "Not yet" nudge and a way to just see it. Name the classic trap explicitly and prove why it is wrong .
- Why text: serif lead sentence, 1–3 glowing `<b>` key phrases per paragraph, parallel facts as `ul.why-chips`. Colour cues: numbers amber, counted objects violet underlined (automatic from `objects` lists).
- History is verified (sources linked; debated claims say so) and told as problem → solution → what it changed, tied back to the lab ("the dashed dot in the model").

## Commands
- `node tools/build-web.js`: builds `app/index.html` (desktop) and `dist-web/inquire-law.html`. Fails on any syntax error.
- `node tools/validate.js [--warnings]`: trees, fields, every lesson, HTML balance, lab coverage, storyboards, chips. Must be 0 errors.
- `node tools/labtest.js`: kit logic tests in `tests/`.
- `node tools/smoke.js` (`ONLY=`): headless Chromium visits every screen at desktop and phone width. `node tools/interact.js`: drives the lesson template's tabs/chips/goals/practice, notes, Assist, right-click, settings, achievements, kit fixture (`tests/fixtures/_kit-demo-lab.js` replaces the template's lab). "folders fold away" is timing-flaky (as in Inquire).
- `npm run check` = build + validate + labtest + smoke + interact (CI: `.github/workflows/check.yml`).
- The device shell can't run Playwright: `node tools/pack.js` (→ `.sync/law.tgz`) → stage → cloud `bash tools/cloud.sh <tgz>`; changes back with `pack.js --changed` / `unpack.js`.
- Release: `npm run release -- patch "note"` (Devon runs it in Terminal once the repo exists).
